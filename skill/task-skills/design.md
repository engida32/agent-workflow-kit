# Design skill
1. State audience, goal and constraints in three lines. If one is missing, make an explicit assumption and write it down.
2. Produce the artifact (document, spec, wireframe, diagram source) as a file.
3. Show key decisions and the alternatives you rejected, each with one-line reasoning.
4. Self-review against every acceptance criterion before finishing; list any you could not meet.

After each meaningful step, record a short progress note (done / in flight / next) so a fresh session can continue.
