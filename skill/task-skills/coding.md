# Coding skill
1. Restate the requirement in one line and list the acceptance criteria you must satisfy.
2. Plan briefly (files, functions, edge cases). Research only if an API or library is unfamiliar.
3. Implement in small files inside the workspace.
4. Run the code or tests with run_command. Read errors fully before changing anything.
5. Fix the root cause, not the symptom. Re-run until checks pass.
6. Finish with: files produced, how to run them, known limits.

After each meaningful step, record a short progress note (done / in flight / next) so a fresh session can continue.
