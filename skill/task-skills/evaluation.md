# Evaluation skill
1. Do not modify the artifact under review.
2. Write the rubric first (3-7 items, each observable).
3. Gather evidence for each item (quote locations, run checks, cite sources).
4. Score each item with a one-line reason; separate must-fix from nice-to-have.
5. Write review.md: verdict, scored rubric, prioritized fixes with concrete suggestions.

After each meaningful step, record a short progress note (done / in flight / next) so a fresh session can continue.
